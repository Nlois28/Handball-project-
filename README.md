# Handball-project-statistics
Handball bundesliga stats 2022-2023
This project analyzes player performance data from the Handball Bundesliga to identify the key metrics that drive success at both the individual and team levels. By leveraging SQL for data extraction and Looker Studio for visualization, the analysis aims to define what makes a player "valuable" in the modern game.

The analysis concludes that the "ideal" modern Bundesliga player is defined by high-efficiency scoring, disciplined ball handling, and proactive, foul-free defense. For clubs, the data suggests that recruiting for efficiency (Percentage) and defensive IQ (Ratio) is more predictive of success than simply looking at total goals scored and the use of roster depth helps the team bring results, plus the importance of the goalkeeper position is one of the most important factors.
